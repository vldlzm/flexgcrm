# flexgcrm

## 프로젝트명
쿠폰기능도입 기획서

## 프로젝트 설명
FlexG CRM 시스템에 쿠폰 기능을 도입하기 위한 기획서 및 구현 문서입니다.

## 프로젝트 구조
```
flexgcrm/
├── index.html          # 메인 페이지
├── css/
│   └── style.css       # 스타일시트
├── js/
│   └── main.js         # 메인 JavaScript
├── assets/             # 이미지, 폰트 등 정적 자산
├── README.md           # 프로젝트 설명서
└── .gitignore          # Git 무시 파일
```

## 주요 기능
- [ ] 쿠폰 발급 기능
- [ ] 쿠폰 조회 기능
- [ ] 쿠폰 사용 기능
- [ ] 쿠폰 만료 관리

## 기술 스택
- HTML5
- CSS3
- Vanilla JavaScript

## 시작하기
1. 프로젝트 폴더로 이동
2. `index.html` 파일을 브라우저에서 열기

## 개발 환경
- 코드 에디터: VS Code
- 브라우저: Chrome/Firefox 최신 버전
